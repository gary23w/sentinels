Open-source host defense

Catch intrusions as they start.

Sentinels runs on your servers and workstations. Its garrett agent detects suspicious activity, can stop the process, and records why it acted.

Detection and response

See why it acted.

Garrett watches processes and their connections on the host. Each case shows the activity it saw, the response mode in use, and the action it took.

Sample case garrett cases

Signal A web server started a shell that tried to download a script.

kill Process ended

In the default mode, Garrett ends the shell and any child processes it started.

pause Awaiting operator

Garrett freezes the process. An operator can review the case and decide whether to stop or release it.

decide Awaiting model

Garrett freezes the process and asks the fleet service’s configured model to stop, release, or hold it.

report Case recorded

Garrett records the signal and lets the process continue. Use this mode to observe what it flags.

Local by default
The agent is a single executable. It scores activity and keeps case records on the host when run standalone.
Reversible cleanup
Garrett can quarantine dropped files and disable persistence. Use garrett restore <case> to reverse cleanup.
Signals for automated intrusions
Garrett looks for patterns such as fast command bursts and repeated attempts. Read about AI-operated intrusions ↗
Performance notes

Internal tests put stopping time at about 20 ms for rapid process-chain scenarios and under 5 ms for selected tool-driven scenarios. These are preliminary figures from those scenarios. See the project notes for context.

Get started

Install Sentinels.

Install the agent on one host, then run garrett status to check it. The default kill mode can end processes it judges hostile.

Linux & macOS

curl -fsSL https://gary23w.github.io/sentinels/install.sh | sudo sh

To start in report mode, use sudo sh -s -- --mode report after the pipe.

Windows PowerShell as administrator

irm https://gary23w.github.io/sentinels/install.ps1 | iex

Or unpack the Windows bundle and run Install garrett.cmd.

After installation

  • garrett status Check the agent
  • garrett cases Review recorded cases
Read the garrett(8) manual ↗
Debian & Ubuntu APT repository 
curl -fsSL https://gary23w.github.io/sentinels/garrett.gpg | sudo tee /usr/share/keyrings/garrett.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/garrett.gpg] https://gary23w.github.io/sentinels stable main" | sudo tee /etc/apt/sources.list.d/garrett.list
sudo apt update && sudo apt install garrett
Signed updates and checksums

Garrett checks the project’s signature before installing an update. Set UPDATE=off to update manually.

Fleet service

Manage cases across hosts.

Run the optional service on your own hardware to collect cases and share learned patterns among enrolled hosts. A configured model can summarize cases and help with decisions in decide mode.

Ask about managed hosting ↗
Set up the fleet service

Linux & macOS

curl -fsSL https://gary23w.github.io/sentinels/service.sh | sudo sh

Windows PowerShell as administrator

irm https://gary23w.github.io/sentinels/service.ps1 | iex

Enroll a host

curl -fsSL https://gary23w.github.io/sentinels/install.sh | sudo sh -s -- --server https://your-service --key <enrollment key>
