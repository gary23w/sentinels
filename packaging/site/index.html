Stop intrusions at the host.

Sentinels is an open-source agent for Linux, macOS and Windows. It detects suspicious processes and records why it acted.

Install Sentinels

Quick install

Linux & macOS

curl -fsSL https://gary23w.github.io/sentinels/install.sh | sudo sh

Windows

Run in PowerShell as administrator.

irm https://gary23w.github.io/sentinels/install.ps1 | iex

Run garrett status to check the agent. The default kill mode can stop processes. Use report mode to evaluate alerts first.

From detection to recovery

Detect locally
One executable watches processes and their connections. Case records stay on the host when it runs standalone.
Choose the response
Stop a suspicious process, pause it for review, or keep it running and record a case.
Review and restore
Run garrett cases to see why it acted. garrett restore <case> can reverse cleanup after a stop.

Deployment and operating notes

Response modes

kill
End the process and its children.
pause
Freeze the process for an operator to review.
decide
Freeze the process and ask the fleet service’s configured model what to do.
report
Record the activity and leave the process running.

On Linux and macOS, install in report mode to review alerts before enabling automatic response.

curl -fsSL https://gary23w.github.io/sentinels/install.sh | sudo sh -s -- --mode report

Fleet service

Run the optional service on your hardware to collect cases and share learned patterns across enrolled hosts.

Linux and macOS

curl -fsSL https://gary23w.github.io/sentinels/service.sh | sudo sh

Windows PowerShell as administrator

irm https://gary23w.github.io/sentinels/service.ps1 | iex

Enroll a host

curl -fsSL https://gary23w.github.io/sentinels/install.sh | sudo sh -s -- --server https://your-service --key <enrollment key>

Packages

The packages are named garrett, after the program they install. The name sentinels works as well: it installs garrett with apt, pacman, dnf and zypper.

For Debian and Ubuntu, add the signed APT repository.

curl -fsSL https://gary23w.github.io/sentinels/garrett.gpg | sudo tee /usr/share/keyrings/garrett.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/garrett.gpg] https://gary23w.github.io/sentinels stable main" | sudo tee /etc/apt/sources.list.d/garrett.list
sudo apt update && sudo apt install garrett

For Arch Linux, add the signed pacman repository.

curl -fsSL https://gary23w.github.io/sentinels/garrett.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key 6857EBCBBEF51040C3F20107362688BFC238AB45
printf '\n[sentinels]\nServer = https://gary23w.github.io/sentinels/arch/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu garrett && sudo systemctl enable --now garrett

For Fedora and RHEL, add the signed RPM repository. On openSUSE, sudo zypper addrepo takes the same file.

sudo curl -fsSL -o /etc/yum.repos.d/garrett.repo https://gary23w.github.io/sentinels/garrett.repo
sudo dnf install garrett && sudo systemctl enable --now garrett

With Homebrew on macOS or Linux, then run the line it prints to start garrett as root from a root-owned folder.

brew install gary23w/sentinels/garrett

With Scoop on Windows, from PowerShell opened as administrator.

scoop install https://gary23w.github.io/sentinels/garrett.json

On Windows, you can also run the Windows Installer package (msiexec /i garrett-windows.msi /qn for Intune and Group Policy), or unpack the Windows bundle and run Install garrett.cmd.

Signed updates

Garrett verifies the project’s signature before updating. Set UPDATE=off to update manually.
