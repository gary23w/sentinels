GARRETT(8) System Administration GARRETT(8)

NAME

garrett - host intrusion sentinel that stops what it catches

SYNOPSIS

garrett enroll --server address [--key key] [--mode kill|decide|pause|report] [--label name]
garrett status
garrett forget
garrett cases
garrett trust|stop|release|restore case
garrett update [--check]
garrett run

DESCRIPTION

garrett watches this machine's running programs and their connections, scores them on the machine, and pauses or ends a program it judges hostile. Installed with nothing else, it protects the machine it is on and keeps its cases there. Enrolled, it reports cases to a Sentinel service that you run, and applies what that service has learned from the rest of your machines.

It normally runs as the garrett systemd service. Enrolling starts the service.

COMMANDS

enroll
Enrol this machine with a Sentinel service and start the service. The enrolment key may be given in the environment variable SENTINEL_ENROLL_KEY instead of on the command line.
status
Show which service this machine reports to, and its response mode.
forget
Stop the service and remove this machine's credential.
cases
List the latest cases on this machine.
trust case
This program is mine: leave it alone from now on.
stop case, release case
Decide a program the agent paused: end it, or let it continue.
restore case
Put back everything that was cleaned up after a stop: quarantined files and switched-off startup entries.
update
Install the newest version now. --check only says whether there is one. The running agent does this by itself a few times a day; see UPDATES.
run
Watch and report in the foreground. The service runs this.

RESPONSE MODES

kill
End a hostile program and everything it started, at once. The default.
decide
Freeze it, then let the service's decision model say stop, release or hold.
pause
Freeze it and wait for an operator.
report
Only report.

The service may hold a machine to a lower mode than it asked for.

FILES

/etc/garrett/garrett.conf
Optional, mode 0600. Lines SERVER=, ENROLL_KEY=, and optionally MODE=, LABEL=, CLEAN=off and UPDATE=off. When this file exists and the machine is not enrolled, the service enrols itself on first start.
/var/lib/garrett/
This machine's credential and what the agent remembers about it.

UPDATES

The running agent asks the project's site a few times a day whether a newer version is out, and installs it. It installs nothing unless the site's list of program files carries the project's signature, names a version newer than the one installed, and matches the file it downloaded. Where this package is installed, apt does the installing from the project's signed repository. UPDATE=off in the configuration file turns this off.

FIREWALL

When the service has fleet blocking on, garrett keeps one nftables table named garrett. It is removed when the service stops and when the package is removed.
