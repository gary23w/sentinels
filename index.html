Automated host intrusion response

Stop the attack before its next command.

Sentinels watches your machines for hostile behavior and can stop a suspicious process while the intrusion is still starting.

Install the agentView source

garrett runs on Linux, macOS and Windows. When a web server starts a shell that downloads a script, garrett can end that shell before the script runs, clean up what it left, and explain why it acted. The agent is one program file. Current release: 1.1.0.

AI-assisted attack frameworks such as ARTEX can work through long attack chains. Sentinels responds to suspicious behavior on the host without waiting for someone to read an alert.

Act, explain, recover

Choose whether garrett ends a hostile process tree, pauses it for a decision, or only reports it. It can quarantine dropped files and disable persistence. Each case shows the reasons for its decision; garrett restore <case> can reverse a mistake.

AI when you choose it

The fleet service can use a configured AI provider for a second opinion and a plain-language case summary. In decide mode, it freezes the suspicious program before asking the model what to do. The default local response path works without an AI provider.

Install on Linux or macOS

curl -fsSL https://gary23w.github.io/sentinels/install.sh | sudo sh

Install on Windows

From an elevated PowerShell:

irm https://gary23w.github.io/sentinels/install.ps1 | iex

Or download garrett-windows.zip, unpack it, and double-click Install garrett.cmd.

That is the whole setup. The machine is protected from that moment. See what garrett has caught with garrett cases.

It keeps itself current

An installed garrett looks here a few times a day and installs each new version by itself. It installs nothing unless the update list carries the project's signature, and the key that makes that signature is kept off this site and off GitHub. To update by hand instead, put UPDATE=off in its configuration file and run garrett update when you like.

Protect a whole fleet

Turn one of your machines into your own service. It makes its keys and certificate, starts, and prints the command that joins the others. It runs on your hardware and your cases stay there. A managed hosted deployment is also available.

curl -fsSL https://gary23w.github.io/sentinels/service.sh | sudo sh

On Windows, from an elevated PowerShell:

irm https://gary23w.github.io/sentinels/service.ps1 | iex

To join a machine to it while installing:

curl -fsSL https://gary23w.github.io/sentinels/install.sh | sudo sh -s -- --server https://your-service --key <enrolment key>

Try it without letting it end anything

curl -fsSL https://gary23w.github.io/sentinels/install.sh | sudo sh -s -- --mode report

apt, by hand

curl -fsSL https://gary23w.github.io/sentinels/garrett.gpg | sudo tee /usr/share/keyrings/garrett.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/garrett.gpg] https://gary23w.github.io/sentinels stable main" | sudo tee /etc/apt/sources.list.d/garrett.list
sudo apt update && sudo apt install garrett

Package signing key: 6857 EBCB BEF5 1040 C3F2 0107 3626 88BF C238 AB45 (garrett.asc). Checksums of every download: SHA256SUMS, signed with that key: SHA256SUMS.asc. The default mode ends a program judged hostile at once, so read the documentation first.
